# 点検野帳 サポートページ

GitHub Pagesで公開する、iPad向け点検支援アプリ「点検野帳」のサポートページです。

## 公開サイトURL

- サポートページ: https://appokayou.github.io/tenken-note/
- プライバシーポリシー: https://appokayou.github.io/tenken-note/privacy.html
- App Store: https://apps.apple.com/jp/app/id6782474651
- 関連アプリ「点検野帳カメラ」: https://appokayou.github.io/tenken-note-camera/
- お問い合わせ: appokayou@gmail.com

## SEO対応内容

- titleタグを「点検野帳｜橋梁・構造物点検をiPadで効率化」に変更
- meta descriptionを、橋梁・道路・構造物点検の記録、図面、写真、コメント管理が伝わる内容に改善
- h1を1つに整理し、h2/h3で「このアプリでできること」「利用シーン」「FAQ」を構成
- ファーストビューに、誰向けか、何ができるか、何が楽になるかを明記
- App Storeへの導線をページ上部、機能説明後、ページ下部に配置
- canonical、Open Graph、Twitter Card、favicon、画像altを追加
- MobileApplicationとFAQPageのJSON-LD構造化データを追加
- robots.txtとsitemap.xmlを追加
- 点検野帳カメラとの相互リンクを追加

## 公開後に行う作業

1. Google Search Consoleで `https://appokayou.github.io/tenken-note/` を登録する。
2. URL検査でトップページを検査し、インデックス登録をリクエストする。
3. サイトマップ `https://appokayou.github.io/tenken-note/sitemap.xml` を送信する。
4. 数日から数週間後に、検索パフォーマンスで「橋梁点検 アプリ」「橋梁点検 iPad」「点検野帳 アプリ」などの表示回数、クリック数、掲載順位を確認する。

## ファイル構成

- `index.html`: 公開サポートページ
- `privacy.html`: プライバシーポリシー
- `robots.txt`: クローラー向け設定
- `sitemap.xml`: 公開ページ一覧
- `app-icon.png`: favicon、OG画像
